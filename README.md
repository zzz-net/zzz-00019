# 本地设备借用归还验收管理系统

一个基于 Python + Tkinter 的桌面 GUI 应用，用于管理投影仪、录音笔等设备的借出、归还和异常冻结流程。

---

## 一、启动步骤

### 环境要求
- Python 3.8 及以上（Tkinter 为 Python 标准库，无需额外安装）

### 运行方式

**方式 1：直接双击运行（推荐）**
```
双击 run.bat
```

**方式 2：命令行运行**
```bash
cd d:\workSpace\AI__SPACE\zzz-00019
python app.py
```

首次启动时，程序会自动在 `data/` 目录下生成以下 JSON 持久化文件并填充样例数据：

| 文件 | 作用 |
|------|------|
| `data/devices.json` | 设备清单（状态、配件等） |
| `data/borrowers.json` | 借用人信息 |
| `data/records.json` | 借用记录与状态历史 |
| `data/users.json` | 用户账号与角色 |
| `data/config.json` | 常用导出目录、上次登录用户 |

关闭程序后数据会自动保存，下次打开仍可查看。

## 三、主流程说明

### 1. 借出登记
1. 左侧设备列表中选中一台**可借出**状态的设备
2. 点击 **"借出登记"** 按钮
3. 选择借用人 → 填写预计归还时间 → 核对配件（必备配件未勾选会警告）→ 填写备注
4. 确认后：设备状态变为 **已借出**，生成一条 **借出中** 的记录

### 2. 提交归还
1. 右侧记录列表中选中一条**借出中**的记录
2. 点击 **"提交归还"**
3. 勾选当前实际归还的配件 → 填写备注
4. 提交后：记录状态变为 **归还验收中**，设备同步变为 **验收中**

### 3. 归还验收
1. 以**验收人**或**管理员**身份登录
2. 选中一条**归还验收中**的记录，点击 **"验收"**
3. 核对归还配件：
   - 若有**必备配件缺失**：记录和设备自动进入 **异常冻结** 状态
   - 配件齐全：记录变为 **已归还**，设备恢复为 **可借出**
   - 可点击 **"强制通过"** 忽略缺失配件完成验收

### 4. 关闭冻结记录（异常处理）
- **借用人不能关闭冻结记录**（界面按钮禁用 + 业务层二次校验）
- 以**验收人**或**管理员**身份：选中**异常冻结**的记录 → 点击 **"关闭冻结"** → 填写处理说明
- 关闭后：记录变为 **已归还**，设备恢复为 **可借出**

### 5. 查看状态历史
选中任意一条借用记录 → 点击 **"查看历史"**，可看到每次状态变更的：
- 时间、原状态、新状态
- 操作人、操作人角色
- 变更说明/备注

## 四、失败路径验证

| 失败场景 | 触发方式 | 预期结果 |
|----------|----------|----------|
| 已借出设备重复借出 | 选中一台"已借出"设备点击"借出登记" | 弹窗提示"已借出，不能再次借出" |
| 缺少必备配件验收 | 归还验收时取消勾选一个【必备】配件 | 记录与设备自动进入【异常冻结】 |
| 借用人关闭冻结 | 切换到 `zhangsan`（借用人）选中冻结记录点"关闭冻结" | 弹窗提示"借用人不能代替验收人关闭冻结记录"，按钮默认禁用 |
| 借用人验收 | 切换到 `zhangsan`（借用人），验收按钮为灰色 | 按钮被禁用，无法操作 |
| 导出目录不可写 | 设置导出目录为 `C:\Windows\System32` 或不存在的只读路径，再点击导出 | 弹出"导出目录不可写"错误，不改动任何选中数据 |
| 冻结设备借出 | 选中"异常冻结"状态的设备点"借出登记" | 提示"处于异常冻结状态，不能借出" |

## 五、数据导出（CSV / JSON）

导出内容与界面列表保持一致：

### 导出设备清单
左侧设备面板 → 点击 **"导出"** → 选择 `.csv` 或 `.json`
- CSV 包含：设备ID、名称、类别、型号、序列号、状态、配件、备注、创建时间

### 导出借用记录
右侧记录列表 → **多选**记录 → 点击 **"导出选中"** → 选择 `.csv` 或 `.json`
- CSV 包含：记录ID、设备、借用人、借出/归还时间、状态、各环节操作员、备注等
- JSON 导出完整对象（含配件核对详情、状态历史）

> 顶部"导出目录"显示状态：【可写】(绿色) / 【不可写】(红色)。目录不可写时任何导出操作都会被拒绝，且不会改动选中数据。
